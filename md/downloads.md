### Windows 7
Windows 7 is probably the best thing Microsoft ever created. And it's still
*very* usable, with period hardware being the only thing that really holds it
back. Like XP, many people kept using it well past its EOL (and still do),
forcing much of the software world to maintain support for it for years, and
even Microsoft themselves to release the occasional patch.

#### Windows Loader by Daz
You cannot buy Windows 7 anymore, so unless you have an old PC with an embedded
license, you cannot activate it either. This tool installs an SLIC certificate
so Windows will activate itself with OEM licensing, and is safe to use on a PC
you will actually use.
